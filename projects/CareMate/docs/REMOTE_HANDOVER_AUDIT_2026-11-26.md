## 재현성 차단 요인

원격 Git 트리 전체를 확인한 결과 `data/` 디렉터리가 없다. 다음 파일은 코드가 직접 읽으므로 원본 복원이 필요하다.

| 파일 | 사용 위치 | 영향 |
| --- | --- | --- |
| `data/inquiries-labeled.json` | `src/app.mjs`의 `loadLabeled()` | 서비스 초기화 및 분류 평가 |
| `data/eval-questions.json` | `test/caremate.test.mjs`, `tools/eval.mjs` | 검색 테스트 및 평가 |

현재 `.gitignore`에는 위 JSON 파일의 제외 규칙이 없다. 상위 저장소나 로컬 전역 ignore 설정 및 원본 파일 존재 여부를 확인한다. 실제 고객 정보나 비밀값이 없는 가상 데이터인지 검토한 후 필요한 원본만 포함한다. 기존 평가 기준을 유지하기 위해 대체 데이터를 임의로 생성하지 않는다.

## 로컬 인수인계 후 검증 절차

