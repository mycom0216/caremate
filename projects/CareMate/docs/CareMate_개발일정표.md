## 3. 위험과 일정 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 평가 세트가 작고 같은 사람이 작성(43문항) | 정확도 과대평가 | 12/05~12/12에 다른 사람이 쓴 질문을 추가해 재측정, 못 하면 한계로 명시 |
| 임베딩 모델(`embeddinggemma`)이 이 PC에서 비정상 종료 | 하이브리드 검색 미검증 | 다른 모델·환경으로 12/12까지 재시도, 안 되면 BM25 기준만 보고하고 미검증으로 표기 |
| 발표 환경에 Ollama 미설치 또는 첫 응답 지연(최댓값 18.9초) | 시연 중단·품질 저하 | 추출형 자동 대체, 서버 시작 때 모델 미리 불러오기(warmup), 시연 전 사전 실행. 단 LLM 없이는 범위 밖 질문 처리가 약해짐을 발표에서 설명 |
