# 데이터 복구 기록 (2026-11-26)

원본 로컬 데이터에 접근할 수 없어 실행에 필요한 대체 데이터를 구성했다. 기존 2026-11-20 평가 원자료 및 결과보고서는 역사적 기록으로 보존한다.

- `data/eval-questions.json`: 기존 `evidence/rag-eval-llm.json`에서 43개 질문과 정답 문서 ID를 그대로 추출했다. 원래 `must` 기준은 기록에 없어 지식베이스를 근거로 새로 작성했다. 따라서 기존 답변 정확도와 직접 비교할 수 없다.
- `data/inquiries-labeled.json`: 지식베이스 기반 가상 문의 8개 유형, 학습 64문장 및 별도 평가 24문장. 원본 분류 데이터가 아니며 기존 분류 정확도 75%의 재현을 주장하지 않는다.
- 실제 고객 개인정보를 사용하지 않았다. 학습·평가 문장은 완전히 동일한 문자열이 없도록 확인했다. 동일 작성자가 구성한 데이터이므로 실제 일반화 성능 검증에는 한계가 있다.

Node.js 24 이상에서 `npm test`, `npm run eval`을 다시 실행해야 한다. 이 커밋 시점에 Node 테스트는 실행하지 못했다. Claude 로컬 원본이 확보되면 대체 데이터와 비교하여 원본을 우선 보존한다.
